# Exercise Image Generation Prompts

## Style Guide

### Style A — "Anatomical Infographic" (for educational breakdowns)
Base prompt suffix: `anatomical infographic illustration style, painterly airbrushed rendering of exposed muscle tissue in warm red-orange-maroon tones with cream highlights, semi-realistic human figure, medical textbook aesthetic, thin leader lines pointing to activated muscles, cream background, editorial science-poster composition, high detail`

### Style B — "Flat Silhouette" (for app UI / muscle selection)
Base prompt suffix: `flat vector silhouette illustration, solid black human figure with thin pale-blue muscle-outline linework overlay highlighting [TARGET MUSCLE], minimalist two-tone fitness-app icon style, symmetrical front view, plain light gray background, blueprint-like anatomical tracing, clean`

### Style C — "Exercise Demo" (for form instruction)
Base prompt suffix: `fitness instruction illustration, clean line art on white background, athletic male figure performing exercise, two positions shown (start and end of movement), arrows indicating direction of motion, muscles engaged highlighted in red overlay, professional gym setting, instructional poster style, no text`


---

## GENERATION TIPS

1. **Batch by muscle group** — All chest first, then back, etc.
2. **Consistent figure** — "athletic male figure, medium build, no face detail"
3. **Two-frame format** — Start + end position for clarity
4. **Red overlay** — Shows activated muscles without being too anatomical
5. **No text in image** — Labels go in the app UI, not baked in
6. **Square 1:1** — 1024×1024 for card display
7. **White/light background** — Contrasts with dark app theme

## FILE NAMING

```
images/[muscle-group]/[##]-[exercise-name-kebab].png
```

Examples:
- `images/chest/01-barbell-bench-press.png`
- `images/back/01-deadlift.png`
- `images/shoulders/01-overhead-press.png`
- `images/quads/01-barbell-back-squat.png`
